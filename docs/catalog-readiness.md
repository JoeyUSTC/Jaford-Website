## 通用待补

- 每个型号的正式规格书（版本、日期、来源、允许公开的范围）。确认存在且允许公开后才添加下载入口。
- 25 个产品条目的实物图片或获准使用的供应商图片；记录来源及使用许可。不要使用订单截图、客户工艺图或生成的仿实拍图。
- 规格书与型号选项的一一对应关系。目前部分选项是需求类型，不是经确认的 SKU。
- 可提供的包装、报价数量、交期与当前供应情况。逐单确认；采购数量不能转换为 MOQ。
- 对性能数据记录测试方法、样品、温度、电压窗口及其他条件，不将目标值写成实测结果。

## 服务确认

- 聚合物/树脂、小分子/配体：结构或 SOP、数量、纯度/杂质、表征和验收方案。重复合成与树脂项目经历不构成通用产能声明。
- 放大/工艺复现：目标批量、原料、安全条件、关键控制点、记录与验收内容；按项目确认合作方条件。
- 碳化/活化：原料适配、工艺与表征需求。水蒸气与 CO₂ 路线须评估。
- 烧结/热处理：正极烧结、磷酸铁锂氧化仍属按项目评估范围，不能作为已完成案例。
- 极片：单/双面计量口径、浆料/配方权限、集流体、加工窗口、裁切及检验标准。
- 软包：叠片与交付状态逐项确认；卷绕、多极耳、锂金属不作普遍可交付承诺。
- 测试：样品、协议、设备范围、原始数据/曲线格式、表征方法与可交付报告，分别约定。
- 科研采购：供应渠道、替代型号、交期、文件和配套交付范围逐单确认，不宣称授权代理。

## 暂不发布为成熟产品或成功案例

CVD 沉硅一体化代工、控氧浸出、回收石墨、特殊硬碳、干法自支撑膜、超薄 PP 网、XAS。若后续新增，需单独提供成熟度和可公开范围依据。

## 实现与询价

- 目录数据：`src/catalog.js`；页面模板：`src/pages.js`；导航及询价：`src/main.js`。
- 产品：`#/products`、`#/products/{id}`；服务：`#/services`、`#/services/{id}`。Hash 路由支持 GitHub Pages 子路径下直接分享、刷新及浏览器返回。
- 询价继承产品/服务及所选型号，生成本地文本与发往 `kiki.li@jaford.com` 的邮件草稿。用户需在邮件客户端发送；网页不会自动提交或确认成功。
- 合作工厂/实验室用于组织服务；JAFORD 为网站品牌。没有将合作伙伴品牌用作 JAFORD 品牌，也没有自有实验室/自产/授权代理声明。
