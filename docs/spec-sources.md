# Public specification references

The owner authorized public-source model/type expansion and reference PDFs. These are original factual technical profiles, not copied supplier datasheets. Catalog information comes from the existing owner-curated records; reference information is separately attributed and never asserted as JAFORD measured performance. Unconfirmed composition, purity, loading, capacity and operating limits remain unclaimed.

All listed product models and material types have a local PDF and in-page dialog. Shared registry: `src/specifications.js`. Generated PDFs: `public/specs/`. Regeneration: `python scripts/generate-specs.py` (ReportLab).
